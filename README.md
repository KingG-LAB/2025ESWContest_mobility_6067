# 2025ESWContest_mobility_6067
2025ESWContest_mobility_6067_비켜요

[작품명]

긴급차량 우선 통행을 위한 실시간 회피 안내 시스템 ; V2X 기반 긴급차량 우선 통행 시스템



[개요]

긴급차량의 신속하고 안전한 통행을 도와 골든타임 확보를 목표로 하는 
실시간 회피 안내 시스템이다.

긴급차량의 출동 정보(ETA, 경로)를 MQTT 기반 V2V/V2I 통신으로 주변 차량에 전파하고,

일반 차량은 전방 카메라(OpenCV)로 현재 차선을 인식 및 검출하여

소방청 길터주기 매뉴얼에 따른 회피 방향을 HUD 및 음성으로 안내받는다.

이를 통해 교차로 중심의 기존 우선신호 시스템을 확장해 도로 전 구간에서 실시간 통행 지원이 가능하다.



[작품 설명]

긴급차량 OBU는 T-DATA Open-API를 호출하여 실시간 교통 상황을 반영한 ETA와 최적 경로를 산출한다. 

이 정보를 MQTT 기반 V2X 통신으로 주변 차량 및 관제센터에 전송한다.
- 근거리 (500m 이내): V2V (Vehicle-to-Vehicle) 통신; 긴급차량이 일반 차량에게 소켓으로 다이렉트 송신한다.
- 원거리 (500m 외): V2I (Vehicle-to-Infrastructure) 통신; 관제센터에서 RSU 모듈을 거쳐 원거리의 차량들에게 데이터를 송신한다.
  RSU 모듈은 도로변 중계기로서 통신 사각지대를 보완하는 역할을 수행한다.
  
일반 차량 OBU는 수신된 정보를 바탕으로 전방 카메라(IMX219)와 OpenCV를 통해 현재 차선을 인식/분석한다. 

이후 소방청 길터주기 매뉴얼에 따른 최적의 회피 방법을 판단하여, 운전자에게 HUD AR 디스플레이와 TTS 음성으로 즉각 안내합니다.



[시스템 구조]

* 긴급차량 OBU
  - T-DATA Open-API 기반 실시간 교통 체증 반영해 ETA 및 최적 경로 계산 수행
  - MQTT를 통해 관제센터 및 반경 500m 내 차량에게 데이터 송신
  - 네트워크 장애 시 캐시 ETA로 임시 대응
    
* 일반차량 OBU
  - IMX219 카메라(OpenCV)로 차선 인식
  - 긴급차 접근 방향 + 메뉴얼 기반 회피 판단
  - HUD(AR 오버레이) 및 TTS 음성으로 회피 방향 안내
    
* RSU 모듈 (도로변 중계기)
  - MQTT 브로커 및 재송신 허브 역할
  - 통신 사각지대 보완 및 다중 차량 동시 대응
