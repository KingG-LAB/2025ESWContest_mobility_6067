긴급차량 우선 통행을 위한 실시간 회피 안내 시스템 ; 긴급차량 우선 통행 시스템 Emergency Vehicle Preemption System

[작품 설명]
긴급차가 출발하면, 실시간 교통 상황을 반영해 계산한 도착예정시간(ETA)과 최적 경로 정보를 근방(500m 이내) 차량에게 즉시 전송하고, 일정 범위를 벗어난(500m 외) 차량에는 도로변 중계기(RSU 모듈)를 통해 전달함. (MQTT)
일반 차량은 전방 카메라로 현재 차선을 인식/분석한 뒤, 소방청 매뉴얼에 따른 어디로 비켜줘야 하는지 회피 방법을 안내받음.
또한, ETA정보를 받아 긴급차량의 도착 예정 시간을 미리 인지헐 수 있음.
운전자는 HUD AR에 표시된 ETA 텍스트와 권장 회피 화살표를 통해 신속·정확하게 길을 비켜 줌으로써, 긴급차량이 신속·안전하게 통과할 수 있도록 지원함.
안내를 인지 못할 경우를 대비하여, TTS 음성 모듈을 동반해 ETA 값과 회피 방향을 안내함.

데이터셋: 긴급차량의 현재 위치, ETA, 회피방향, 신호등 제어 신호, 긴급차량 근방 유무 신호 등
여러 데이터를 하나의 JSON 객체로 묶어 전송함
해당 노드(객체)에게 모든 데이터를 전송할 경우, 불필요한 정보까지 제공될 수 있으며 전송량 혹은 처리 및 송신 속도에 영향을 줄 수 있음.
따라서 해당 대상에 필요한 정보를 보내주는 방식으로 진행함. 선택적 데이터 전송(Selective Data Transmission)으로 진행함.
